2. معلومات عامة عن المشروع (Project Overview):
--------------------------------------------------------------------------------
- اسم المشروع: WeatherMap SPA — Asynchronous Weather & Geolocation Application
- التقنيات المستخدمة: 
  * Pure Vanilla JavaScript (ES6+) — بدون أي أطر عمل أو مكتبات مثل React أو jQuery
  * Semantic HTML5 — التزام تام بمبدأ الفصل (Separation of Concerns)
  * Vanilla CSS3 — تصميم Apple Weather Minimalist Glass بدون Tailwind أو Bootstrap
  * Leaflet.js — خريطة تفاعلية مفتوحة المصدر (OpenStreetMap)
  * OpenWeatherMap REST API — استدعاء بيانات الطقس اللحظية


3. مطابقة الشروط الأكاديمية الدقيقة (Academic Requirements Met):
--------------------------------------------------------------------------------
[✓] الفصل الكامل بين الملفات (Separation of Concerns):
    - index.html: الهيكل الدلالي فقط.
    - css/style.css: التصميم والتنسيق بالكامل.
    - js/config.js: مفاتيح ومحددات الـ API المضمنة مسبقاً.
    - js/app.js: المنطق البرمجي، وجميع معالجات الأحداث عبر addEventListener.
    - لا يوجد أي inline styles أو inline onclick.

[✓] تطبيق صفحة واحدة بدون إعادة تحميل (Zero Full-Page Reloads):
    - منع إعادة التحميل الافتراضية عبر event.preventDefault().
    - جميع الطلبات تتم عبر Fetch API بصورة غير متزامنة (Asynchronous).

[✓] أبعاد الخريطة بدقة:
    - الخريطة تشغل تماماً 70% من ارتفاع نافذة العرض (70vh).
    - إطار كحلي/فحمي أنيق مع زوايا ناعمة وتأثير زجاجي.

[✓] نقطة البداية الافتراضية (Baseline Coordinates):
    - الخرطوم، السودان (خط عرض 15.5007، خط طول 32.5599) بمستوى تقريب Zoom = 6.

[✓] تدفق البيانات المزدوج (Multi-API Integration):
    - استدعاء OpenStreetMap Nominatim Geocoding لتحويل اسم المدينة إلى إحداثيات.
    - استدعاء OpenWeatherMap API لجلب حالة الطقس، درجات الحرارة، سرعة الرياح، الرطوبة، والسحب.

[✓] شاشة التحميل ومعالجة الأخطاء (Loading & Error Handling):
    - مؤشر تحميل CSS (Spinner) أثناء انتظار استجابة الخادم.
    - بطاقات تنبيه عائمة تظهر للمستخدم بوضوح عند حدوث خطأ في الشبكة أو عدم العثور على المدينة (404).

[✓] الميزات الإضافية المتقدمة (Bonus Features):
    - المفضلة عبر التخزين المحلي (LocalStorage Favorites).
    - النقر المباشر على الخريطة للاستعلام (Click-to-Inspect Weather).
    - التبديل الفوري بين الدرجة المئوية والفهرنهايت (°C / °F).
    - مشاركة الطقس عبر فيسبوك، واتساب، وWeb Share API.
    - تحديد الموقع الجغرافي الفوري عبر GPS (Locate Me).
    - مساعد الطقس الذكي التفاعلي (Weather AI Advisor).
